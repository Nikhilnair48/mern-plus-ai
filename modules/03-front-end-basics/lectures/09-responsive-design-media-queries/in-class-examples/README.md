## Suggested live-code flow

1. Open `3-course-landing-page-baseline.html` and resize the browser.
2. Compare `4-fixed-width-course-info.html` and `5-percentage-width-course-info.html`.
3. Demonstrate `8-rem-course-card.html`, `10-viewport-hero.html`, and `12-em-component.html`.
4. Use `13-responsive-navigation.html` to introduce Media Queries.
5. Compare files 16 and 17 for Desktop-First vs Mobile-First.
6. Build file 20 progressively until it matches file 21.
