# Instructor files

Open files in slide order. Each file is independent and can be pasted directly into TypeScript Playground.

## Comment labels

- `DEMO`: what to point out
- `INSTRUCTOR EDIT`: the small live change to make
- `EXPECTED DIAGNOSTIC`: the intended static feedback
- `EXPECTED INFERRED TYPE`: the expected hover result
- `EXPECTED OUTPUT`: the runtime result
- `RESET`: how to restore the valid state
- `BROKEN ON PURPOSE`: an intentional practice error
