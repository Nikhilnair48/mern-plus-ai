# Learner files

These files support Lecture 15 practice in TypeScript Playground.

## How to use a file

1. Open https://www.typescriptlang.org/play
2. Select TypeScript.
3. Paste one file into the editor.
4. Follow the `LEARNER TRY` or `LEARNER TODO` comments.
5. Read diagnostics before changing the type.
6. Run only when the file is in a valid state.
