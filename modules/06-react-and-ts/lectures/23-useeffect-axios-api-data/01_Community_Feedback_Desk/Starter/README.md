# Community Feedback Desk — Starter

Instructor starting project for **Lecture 23, beginning at Slide 10**.

## Run

```bash
npm install
npm run dev
```

Axios is intentionally not installed yet. Install it live at **Slide 33**:

```bash
npm install axios
```

## Starting point

- `TabActivityDetector` already stores `wasBackgrounded` and has a working Reset button.
- It does not yet register a browser listener.
- `FeedbackInbox` is only a placeholder.
- `main.tsx` already uses Strict Mode.
