# Support dashboard starter

This is the runnable starter for the main Lecture 20 code-along.

## Run the project

```bash
npm install
npm run dev
```

## Starting structure

```text
SupportDashboard
├── DashboardHeader
├── TicketQueue
│   └── TicketRow
│       └── TicketActions
└── EscalationPanel
```

The ticket data already moves down through typed props. The **Escalate** buttons are intentionally inactive at the start of the lecture.

Use the project as provided until the instructor asks you to make a change.
